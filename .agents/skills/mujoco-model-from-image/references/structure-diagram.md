# 简化结构图的固定格式

写 MJCF 之前，先用这个格式把「打算怎么建」摊开给用户看。五部分齐全，缺一部分都不算交付。

所有数字只有一个来源：**连杆尺寸表**。示意图里标符号（T、P、t、s、f），不标数字，避免两处数字对不上。

---

## 1. 层次树

缩进表示父子关系，标出 body 名与关节名，关节挂在它驱动的那个 body 上。

```text
base（浮动基座，freejoint: root）
├─ torso            [joint: waist_yaw]
├─ thigh_L          [joints: hip_roll_L, hip_pitch_L]   ← 同一点两个 DOF 放同一个 body
│  └─ shank_L       [joint: knee_L]
│     └─ foot_L     [joint: ankle_L]
└─ thigh_R          [joints: hip_roll_R, hip_pitch_R]
   └─ shank_R       [joint: knee_R]
      └─ foot_R     [joint: ankle_R]
```

## 2. 示意图

至少一张正视或侧视的骨架图，标出连杆符号和关节位置。

```text
       ┌──────────┐        ← T  torso
       └────┬─────┘
            │             ← 关节 waist_yaw
        ┌───┴────┐        ← P  pelvis
        │        │
   ┌────┴───┐ ┌──┴────┐
   │   t    │ │   t   │   ← 关节 hip_roll / hip_pitch
   └────┬───┘ └──┬────┘
   ┌────┴───┐ ┌──┴────┐
   │   s    │ │   s   │   ← 关节 knee
   └────┬───┘ └──┬────┘
  ▀▀▀▀▀▀▀▀  ▀▀▀▀▀▀▀▀    ← 关节 ankle，f = foot
```

坐标约定写在图下面一行：`x 前 / y 左 / z 上；俯仰正角 = 前摆`。

## 3. 连杆尺寸表

| 连杆 | 形状 | 全尺寸 (x, y, z) | 相对父关节偏移 | 来源 |
| --- | --- | --- | --- | --- |
| pelvis | box | 0.090 × 0.120 × 0.040 | — | 按比例 |
| torso | box | 0.080 × 0.110 × 0.090 | z +0.020 | 按比例 |
| thigh | box | 0.040 × 0.040 × 0.080 | z −0.020 | 按比例 |
| shank | box | 0.036 × 0.036 × 0.080 | z −0.080 | 按比例 |
| foot | box | 0.100 × 0.050 × 0.020 | z −0.080 | 按比例 |

「来源」列必须填：`实测` / `按比例` / `假设`。这一列是给用户看的，也是建模时唯一被允许的猜测来源。

## 4. 关节表

| 关节 | 父 → 子 | 类型 | 轴 | 范围 (rad) | 驱动 |
| --- | --- | --- | --- | --- | --- |
| waist_yaw | pelvis → torso | hinge | (0, 0, 1) | ±1.57 | 是 |
| hip_roll | pelvis → thigh | hinge | (±1, 0, 0) | ±0.35 | 是 |
| hip_pitch | pelvis → thigh | hinge | (0, −1, 0) | [−0.90, 1.20] | 是 |
| knee | thigh → shank | hinge | (0, −1, 0) | [−1.60, 0.05] | 是 |
| ankle | shank → foot | hinge | (0, −1, 0) | [−0.60, 0.80] | 是 |

最后一行给合计：`共 N 个驱动关节，nq = 7 + N`。

## 5. 假设与待确认清单

每条都写成「项 → 当前取值 → 为什么这么取」，方便用户一眼否决：

- 总高：0.31 m —— 图里没有标尺，按桌面级机器人取，其余尺寸按图比例缩放。
- 腿部只有矢状面 DOF：+0 外展 —— 图里侧面看不到外展关节，保守处理。
- 足部是刚性矩形 —— 图里像橡胶垫，暂不建柔顺。
- 颜色/材质：不参与仿真，仅按图配色。

最后附一句确认话术：

> 请确认三点：① 拓扑和连杆数对不对；② 关节数量/轴向对不对；③ 按总高 0.31 m 等比缩放可不可以。确认后我直接出 MJCF。

## 反例

不要这样交付：

```text
我打算建一个双足机器人模型，有腰和两条腿，关节应该够用了。
```

问题：没有拓扑、没有尺寸、没有 DOF 表、没有可确认的假设——用户无法判断对错，后面必然返工。
